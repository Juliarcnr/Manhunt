# Manhunt

Private App (Android/iOS, Deutsch/Englisch) zum Spielen von „Manhunt“: Hunter jagen Spieler in einem
festgelegten Gebiet, Standorte werden automatisch in Intervallen geteilt, inklusive Speedhunts und Joker.

- Anforderungen: [docs/requirements.md](docs/requirements.md)
- Architektur & Stand: [docs/architecture.md](docs/architecture.md)
- Datenschutz: [docs/privacy.md](docs/privacy.md)
- **Vor dem Spiel lesen:** [docs/BeforeYourGame.md](docs/BeforeYourGame.md)
